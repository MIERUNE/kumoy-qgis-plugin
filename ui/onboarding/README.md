# オンボーディング用の概念図

`ja/` は日本語、`en/` は英語。それ以外の言語では英語画像を表示する。
SVG はスクリーンショットを data URI で内包し、プラグインに同梱する。
表示時の通信や外部ファイルへの参照は不要。

図の主役は QGIS と Kumoy クラウドの関係とデータの流れ。
実画面は、その流れに関わるメニュー・ボタン・ダイアログだけを切り出している。
地図キャンバスのスクリーンショットは使用しない。

| ファイル名 | 内容 |
| --- | --- |
| `login.svg` | QGIS でログイン開始 → Web でサインイン・接続を承認 → QGIS が認証結果を受け取りログイン完了 |
| `project.svg` | Org → Team → Project → Data の階層と、ひとつのプロジェクトを選んで作業する概念 |
| `upload.svg` | Upload Vector メニューと、手元の GIS データをクラウドに保存する流れ |
| `read.svg` | ブラウザ・読み込みメニューと、クラウドの Map / Vector / Raster を QGIS で利用する流れ |
| `edit.svg` | 実際の Current Edits サブメニューの保存項目と、変更をクラウドへ反映する流れ |
| `publish.svg` | 公開チェックボックス・公開ページのメニューと、クラウドの地図を公開 URL で世界に共有する流れ |

## 実画面の出典

- QGIS の画像は QGIS 4.0 の隔離プロファイルとオフラインのサンプルデータで撮影。
  実アカウントの組織・プロジェクト・個人情報は含まない。
  ログイン完了ダイアログも実際の UI をサンプル状態で表示して撮影したもの。
- Web の画像は 2026-10-22 に `https://app.kumoy.io` の実際のサインイン画面を撮影。
  メールアドレス等の認証情報は入力していない。Web の画像は両言語とも同じ英語画面。
- ログイン完了の矢印は、現行の Device Authorization Flow で QGIS が認証結果を
  受け取ることを表す。ローカル HTTP コールバックを使う実装ではない。

差し替える場合は、両言語の図と `dialog_onboarding.py` の説明文を合わせて更新する。
図のサイズは 1060 × 700 px。図全体と内包する実画面のアスペクト比を維持すること。
スクリーンショット以外のラベル・矢印・カードは SVG ソースを直接編集できる。
